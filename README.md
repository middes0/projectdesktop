# PROJECT DESKTOP

Desktop virtual experimental feito com HTML, CSS e JavaScript, sem dependências ou etapa de build.

## Rodar localmente

Abra `index.html` em um navegador.

## Publicar no Cloudflare Pages

1. Entre no Cloudflare Dashboard e abra **Workers & Pages**.
2. Crie um projeto Pages conectado ao repositório `middes0/projectdesktop`.
3. Selecione a branch `main`.
4. Como não há etapa de build, deixe **Build command** vazio.
5. Defina **Build output directory** como `/`.
6. Salve e aguarde a publicação.

Os aplicativos desta versão são demonstrações no navegador. As notas ficam no armazenamento local do navegador; o explorador não acessa automaticamente os arquivos privados do dispositivo.
